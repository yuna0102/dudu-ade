# Dudu ADE

[Orca](https://github.com/stablyai/orca)를 포크해서 제가 쓰기 편하게 고친 버전이에요.
터미널과 Claude 채팅 창을 무한 캔버스(보드) 위에 카드로 펼쳐 놓고, 한눈에 보면서 일할 수 있어요.
에이전트를 여러 개 동시에 돌리는 분께 특히 잘 맞아요.

> 맥 Apple Silicon(M1 이상)에서만 동작해요. 인텔 맥과 윈도우는 아직 지원하지 않아요.

## 원본과 다른 점

- **보드**: 열려 있는 터미널과 채팅이 전부 카드로 보여요. 위치와 크기를 바꿔도 앱을 다시 켜면 그대로예요
- **영역(카테고리)**: 카드 여러 개를 묶고 색과 이름을 붙일 수 있어요. 피그마의 섹션과 비슷해요
- **연결선**: 카드끼리 선으로 이어서 "이 창이 끝나면 저 창에 넘겨요" 같은 규칙을 적어 둘 수 있어요
- **산출물 모아 보기**: 각 창이 만든 파일(md, html, 이미지 등)이 카드 옆에 자동으로 붙어요
- **터미널과 채팅 전환**: 같은 대화를 터미널로 보다가 채팅 화면으로 바꿀 수 있어요
- **알림 아이콘**: 답을 기다리거나 작업이 끝난 창은 종 아이콘으로 알려 줘요

## 설치

1. [Releases](../../releases/latest)에서 가장 최신 `dudu-ade-macos-arm64.dmg`를 받아요
2. dmg를 열고 `Dudu ADE`를 원하는 위치로 옮겨요. 보통은 응용 프로그램 폴더예요
3. 처음 실행할 때 "확인되지 않은 개발자"라며 막히면, 터미널에서 아래처럼 입력해요

```
xattr -dr com.apple.quarantine <Dudu ADE.app 위치>
```

`<Dudu ADE.app 위치>`는 직접 쓰지 않아도 돼요. `xattr -dr com.apple.quarantine ` 까지만 입력하고, 한 칸 띄운 뒤 Finder에서 앱 아이콘을 터미널 창으로 끌어다 놓으면 경로가 자동으로 들어가요. 그다음 Enter를 누르세요.

애플 개발자 인증을 받지 않은 개인 빌드라서 생기는 안내예요.

## 새 버전 받기

- 저장소 오른쪽 위의 **Watch → Custom → Releases**를 체크해 두면 새 버전이 올라올 때 알림이 와요
- 업데이트는 새 dmg를 받아서 기존 앱 위에 덮어쓰면 끝이에요. 앱은 먼저 종료해 주세요
- 보드 배치, 영역, 연결선은 앱 안이 아니라 내 컴퓨터의 설정 폴더에 저장돼요. 덮어써도 사라지지 않아요
- 덮어쓴 뒤 다시 막히면 위의 `xattr` 명령을 한 번 더 실행하면 돼요

## 사용법

왼쪽 사이드바에서 **보드**를 누르면 열려요. 터미널이나 에이전트가 하나라도 켜져 있어야 카드가 보여요.

| 하고 싶은 일                 | 방법                                              |
| ---------------------------- | ------------------------------------------------- |
| 보드 이동                    | 휠 스크롤, 또는 Space / H를 누른 채로 드래그      |
| 확대와 축소                  | Cmd + 휠                                          |
| 카드 여러 개 선택            | Shift + 클릭, 또는 빈 곳을 끌어서 상자 선택       |
| 카드 안에서 터미널 쓰기      | 카드를 클릭해서 포커스. 빠져나올 때는 Shift + Esc |
| 터미널 글자 크기             | 카드에 포커스한 상태에서 Cmd + / Cmd -            |
| 카드 연결                    | 카드 오른쪽의 점을 다른 카드로 끌기               |
| 새 터미널, 메모, 영역 만들기 | 위쪽 툴바의 **+ 추가**                            |
| 보드에 없는 창 올리기        | 툴바의 **보드에 없는 창 추가**                    |
| 산출물만 모아 보기           | 사이드바의 **자산**                               |

## 자주 쓰는 명령어

앱 안의 터미널에서 `orca` 명령을 쓸 수 있어요.

```
# Claude를 채팅 화면으로 열기 (이전 대화를 이어서 열려면 --resume 추가)
orca agent launch --agent claude --surface chat

# 열려 있는 터미널 목록
orca terminal list

# 다른 창에 메시지 보내기 (handle은 terminal list에서 확인)
orca terminal send --terminal <handle> --text "할 일" --enter
```

창끼리 `orca terminal send`로 주고받으면 보드에 데이터가 오가는 선이 그려져요.

## 알아 두면 좋은 점

일부 기능은 제 작업 환경을 기준으로 만들어져서, 다른 맥에서는 다르게 동작할 수 있어요.

- MD 문서 카드, 아티팩트 카드, 보드 배치 파일은 기본적으로 홈 폴더의 `dudu-ade` 폴더를 사용해요. 위치와 선택 기능은 아래 설정으로 바꿀 수 있어요

### 설정 (선택)

`~/.dudu-ade/config.json` 파일을 만들면 돼요. 모든 항목은 선택이고, 같은 이름의 환경변수가 있으면 환경변수가 우선해요. Dock 이나 Finder 로 켠 앱은 터미널 환경변수를 받지 못하니 이 파일을 쓰는 편이 안전해요.

```json
{
  "outDir": "~/dudu-ade",
  "deskFile": "~/.dudu-ade/desk.json",
  "excludeDirs": ["~/private-notes"]
}
```

| 항목          | 환경변수                             | 기본값                  | 용도                                                            |
| ------------- | ------------------------------------ | ----------------------- | --------------------------------------------------------------- |
| `outDir`      | `DUDU_ADE_OUT_DIR`                   | `~/dudu-ade`            | 문서, 아티팩트 페이지, `INDEX.md`, 보드 배치 파일을 두는 폴더   |
| `deskFile`    | `DUDU_ADE_DESK_FILE`                 | `~/.dudu-ade/desk.json` | 창 이름과 대화 번호가 적힌 파일. 없으면 역할 이름 표시만 꺼져요 |
| `excludeDirs` | `DUDU_ADE_EXCLUDE_DIRS`(쉼표로 구분) | 없음                    | 이 폴더 아래 파일과 대화는 보드 자산 목록에 넣지 않아요         |

`outDir` 를 바꾸면 보드 배치 파일 위치도 같이 바뀌니, 기존 `dudu-ade` 폴더를 새 위치로 옮겨 주세요.

- 이름 기준으로 보드 배치를 복원하는 기능은 제가 쓰는 역할 창 이름에 맞춰져 있어서, 처음에는 카드가 자동으로 정렬되지 않을 수 있어요
- 보드, 터미널, 채팅 카드의 기본 기능은 환경과 상관없이 동작해요

## 직접 빌드하기

Node 24와 pnpm이 필요해요.

```
pnpm install
pnpm dev          # 개발 모드로 실행
pnpm build:mac    # dist/mac-arm64/ 에 앱 생성
```
